\section{Experiments}
\label{sec:experiments}

\subsection{Synthetic Gaussians}
We first consider a synthetic mixture of Gaussian setting---a simple multimodal benchmark that
evaluates the ability of sampling methods to capture all modes of a distribution. 
We compare Euc-PD, WFR, WIFT, and MSIP for the two-dimensional target $\pi=\mathcal{N}(\bm{0},I_2)$. Every run uses $N=20$ particles, seed $42$, RBF length scale $1$, and $1000$ iterations. The close and far initial distributions are $\mathcal{N}((1,1),I_2)$ and $\mathcal{N}((9,9),I_2)$, respectively. Euc-PD, WFR, and WIFT use the linear-plus-RBF kernel with unit linear coefficient, whereas the upstream MSIP implementation uses the RBF kernel. We use $\alpha=1$ and $\beta=0.5$ and report unsmoothed trajectories.

Figure~\ref{fig:all_mmd} compares $\tau\in\{0.01,0.1,1\}$. The MSIP curve for $\tau=1$ is omitted because the upstream update encounters a singular Gram matrix in both initialization settings. Appendix~\ref{app:distant-initialization} provides the corresponding particle trajectories.

\subsection{Mean-field student-teacher neural networks}
We next test the particle geometries in a nonlinear regression problem. For an input $z\in\R^d$, the student network is $f_{\mu_N}(z)=\sum_{i=1}^N w^{(i)}\sigma(z^\top\theta^{(i)})$, where the hidden parameters $\theta^{(i)}$ are the particle locations and the outer coefficients $w^{(i)}$ are their weights. The teacher $f_\star$ has the same two-layer mean-field form with $M$ hidden features. For fixed inputs $z_1,\ldots,z_L$, we use the empirical feature kernel $k(\theta,\theta')=L^{-1}\sum_{\ell=1}^L\sigma(z_\ell^\top\theta)\sigma(z_\ell^\top\theta')$. With residuals $r_\ell=f_{\mu_N}(z_\ell)-f_\star(z_\ell)$, the resulting MMD is exactly the root-mean-square student--teacher mismatch:
\begin{align*}
    \mmd^2(\mu_N,\pi_M)
    &= \frac{1}{L}\sum_{\ell=1}^L r_\ell^2.
\end{align*}

We use ReLU activation, dimension $d=5$, $N=40$ student particles, $M=20$ teacher features, and $L=256$ fixed inputs. The inputs follow $\mathcal{N}(\bm{0},I_d/d)$, while both the teacher hidden parameters and the initial student particles follow $\mathcal{N}(\bm{0},I_d)$. The teacher outer coefficients follow $\mathcal{N}(0,1/M)$. We fix the student, teacher, and input seeds to $42$, $123$, and $456$, respectively, use $\alpha=1$ and $\beta=0.5$, and run every method for $100$ iterations without projecting the weights.

Figure~\ref{fig:mean-field-nn} compares $\tau\in\{0.003,0.01,0.03,0.1,0.3\}$.

    \centering

    \caption{\textbf{Mean-field ReLU student--teacher network with $d=5$, $N=40$, and $M=20$.} MMD trajectories for Euc-PD, WFR, and WIFT over $100$ iterations and $L=256$ fixed inputs.}

The larger tested step sizes initially decrease the MMD more rapidly, while WIFT obtains the lowest errors for $\tau\in\{0.03,0.1,0.3\}$ and plateaus near $0.08$ for $\tau\in\{0.1,0.3\}$. At iteration $100$, the best final MMD over the tested step sizes is $0.127$ for Euc-PD, $0.178$ for WFR, and $0.081$ for WIFT.
